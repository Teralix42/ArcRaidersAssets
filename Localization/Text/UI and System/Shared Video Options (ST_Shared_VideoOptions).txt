Dynamic presets can only be enabled if you GPU supports DirectX 12 and hardware-accelerated ray tracing.

[ID_SHARED_VIDEO_OPTION_RTXGI_TOOLTIP]
NVIDIA RTX Global Illumination calculates bounce lighting across the scene.

"Static" preset uses pre-calculated lighting data, and has the smallest performance cost.
"Dynamic" presets use real-time ray tracing to update bounce lighting as lighting and environmental changes happen. From "Dynamic - Low" to "Dynamic - Epic", RTXGI traces more and more rays in order to update lighting faster.

Higher "Dynamic" presets have a major impact on GPU performance, and enabling any "Dynamic" mode will have a minor impact on CPU render performance.

[ID_SHARED_VIDEO_OPTION_VSYNC_TOOLTIP]
Turn VSync on to synchronize the game's frame rate with the refresh rate of your monitor and eliminate screen tearing.

This can introduce some additional input latency and can cause frame stuttering in case the game's frame rate is lower than the monitor refresh rate.

Keep this off for variable refresh-rate displays.

[ID_SHARED_VIDEO_OPTION_WINDOW_MODE]
Window Mode

[ID_SHARED_VIDEO_OPTION_WINDOW_MODE_FULLSCREEN]
Exclusive Fullscreen (Not Recommended)

[ID_SHARED_VIDEO_OPTION_WINDOW_MODE_TOOLTIP]
Controls which window mode the game will use.

In Borderless Fullscreen mode the game will create a full screen window without borders that fits exactly on your monitor. This is the recommended way to play the game full screen.

In Windowed mode the game will run in a resizable window.

In Exclusive Fullscreen mode, the game will take exclusive control over your monitor and its resolution. This is a legacy Windows feature that we do not recommend using. It can cause switching between applications on your PC to become slow and stuttery, while giving no performance benefit on modern Windows versions.
